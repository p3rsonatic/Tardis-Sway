# Tardis-Sway
p3rsonatic's Sway environment install script 

## Idea

A literate programming file in org-babel + a single file install.sh script to install and configure all the software I like for a computer.
It works on Linux Mint and LMDE, I suppose perhaps on Debian and Ubuntu too. 

The idea is to use software that is quite minimal (lines of code), performant, small, but accessible. So for example using nmtui for wifi, blueman GUI for bluetooth, so anyone can use it. Not only that but waybar has a Help menu that teaches the user how to use the tiling window manager, open apps, close apps, etc.
