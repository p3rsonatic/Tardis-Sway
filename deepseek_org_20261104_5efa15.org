* How to use and edit this file

  This file tangles into a single =install.sh= that installs the
  TARDIS-blue Sway desktop. Each heading below is a *module*: one
  self-contained concern.

  **Contract for edits.** When you ask for a change, only ONE module is
  replaced. You receive: the module's number + name, and the new
  =#+BEGIN_SRC= block. Nothing else in this file changes. That is how
  we avoid "fixed the resize, broke the bar" regressions.

  **Tangle and run.**

  #+BEGIN_EXAMPLE
    emacs --batch install.org -f org-babel-tangle
    # or: C-c C-v t  (in Emacs)
    chmod +x install.sh   # only if Emacs didn't already
    ./install.sh
  #+END_EXAMPLE

  **Verify before running.**

  #+BEGIN_EXAMPLE
    bash -n install.sh    # syntax check; must be silent
    grep -c '__[A-Z_]*__' install.sh   # placeholders remaining; expect 0
  #+END_EXAMPLE

  **Ordering invariants (do not reshuffle).**

  - Module 1 defines =log=, =warn=, =fail=, =DOTFILES=, =LOG=. Every
    later module depends on these.
  - Module 23 (polkit binary) must run *after* Module 8 wrote the sway
    config, because it substitutes =__POLKIT__= inside it.
  - Module 26 (verification) must be the last thing before the final
    message. It is the hard gate.

* Module 1 — Header, globals, helpers, pre-flight, keyboard detection
  :PROPERTIES:
  :CUSTOM_ID: m1-header
  :END:

  Shebang, strict mode, global paths, the three logging helpers, and
  the root/sudo guard. Truncates the install log so re-runs get a
  fresh file. Detects the X11 keyboard layout so Module 8 can bake it
  into the sway config — no placeholders, no `[XKB-338]` risk.

  **Override** if auto-detection is wrong:
  #+BEGIN_EXAMPLE
    FORCE_LAYOUT=1 XKB_LAYOUT_OVERRIDE=br XKB_VARIANT_OVERRIDE=abnt2 ./install.sh
  #+END_EXAMPLE

#+NAME: m1-header
#+BEGIN_SRC bash
#!/usr/bin/env bash
# install.sh — one-shot installer for the TARDIS-blue Sway desktop.
# Generated from install.org by org-babel-tangle. Edit install.org, not this.
# Tested on Debian 12, LMDE 6, Ubuntu 24.04.
set -euo pipefail

DOTFILES="$HOME/dotfiles"
CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}"
LOCALBIN="$HOME/.local/bin"
LOG="$HOME/.dotfiles-install.log"

log()  { printf '\033[1;38;5;33m==>\033[0m %s\n' "$*"; }
warn() { printf '\033[1;33m!!!\033[0m %s\n' "$*"; }
fail() { printf '\033[1;31mXXX\033[0m %s\n' "$*" >&2; exit 1; }

[ "$EUID" -eq 0 ] && fail "Do not run as root."
sudo -v || fail "sudo required."
: > "$LOG"

# ── Keyboard detection ───────────────────────────────────────────────
# Order of preference: explicit override → /etc/default/keyboard
# (what Cinnamon's keyboard settings and localectl write to) → localectl
# → "us". Sanitized so a stray space can't break sway's parser.
XKB_LAYOUT="us"
XKB_VARIANT=""
KB_SRC="default"
if [ "${FORCE_LAYOUT:-0}" = "1" ] && [ -n "${XKB_LAYOUT_OVERRIDE:-}" ]; then
  XKB_LAYOUT="$XKB_LAYOUT_OVERRIDE"
  XKB_VARIANT="${XKB_VARIANT_OVERRIDE:-}"
  KB_SRC="env override"
elif [ -f /etc/default/keyboard ]; then
  # shellcheck disable=SC1091
  . /etc/default/keyboard 2>/dev/null || true
  XKB_LAYOUT="${XKBLAYOUT:-us}"
  XKB_VARIANT="${XKBVARIANT:-}"
  KB_SRC="/etc/default/keyboard"
elif command -v localectl >/dev/null 2>&1; then
  XKB_LAYOUT=$(localectl status 2>/dev/null | awk -F: '/X11 Layout/ {gsub(/ /,"",$2); print $2}' | cut -d, -f1)
  XKB_VARIANT=$(localectl status 2>/dev/null | awk -F: '/X11 Variant/ {gsub(/ /,"",$2); print $2}' | cut -d, -f1)
  KB_SRC="localectl"
fi
XKB_LAYOUT=$(printf '%s' "${XKB_LAYOUT:-us}" | tr -d '[:space:]')
XKB_VARIANT=$(printf '%s' "${XKB_VARIANT:-}" | tr -d '[:space:]')
[ -z "$XKB_LAYOUT" ] && XKB_LAYOUT="us"
log "Keyboard: layout='$XKB_LAYOUT' variant='${XKB_VARIANT:-<none>}' (source: $KB_SRC)"

#+END_SRC

* Module 2 — Repair half-configured dpkg state
  :PROPERTIES:
  :CUSTOM_ID: m2-dpkg
  :END:

  A failing unrelated package (e.g. =virtualbox-dkms=) leaves dpkg in
  "half-configured" state, which makes every subsequent =apt install=
  abort with exit 11. Attempt recovery; do not fail if recovery fails
  — Module 5's critical-package gate is the real safety net.

#+NAME: m2-dpkg
#+BEGIN_SRC bash
log "Checking dpkg state…"
if [ -z "$(sudo dpkg --audit 2>/dev/null)" ]; then
  log "dpkg state OK."
else
  warn "dpkg has half-configured packages; attempting recovery…"
  sudo dpkg --configure -a >>"$LOG" 2>&1 \
    || warn "dpkg --configure -a failed (see $LOG). Continuing anyway."
fi

#+END_SRC

* Module 3 — Detect polkit agent package
  :PROPERTIES:
  :CUSTOM_ID: m3-polkit-pkg
  :END:

  =polkit-gnome= is absent from Debian 12 and Ubuntu 24.04.
  =lxpolkit= is the lightest working agent; =mate-polkit= is fallback.
  Aborts if neither is available — there is no acceptable "no polkit"
  outcome for a shared desktop.

#+NAME: m3-polkit-pkg
#+BEGIN_SRC bash
sudo apt-get update -qq >>"$LOG" 2>&1 || warn "apt update returned non-zero."

POLKIT_PKG=""
for p in lxpolkit mate-polkit; do
  if apt-cache show "$p" >/dev/null 2>&1; then
    POLKIT_PKG="$p"
    break
  fi
done
[ -z "$POLKIT_PKG" ] && fail "No polkit agent in apt (tried lxpolkit, mate-polkit)."
log "Polkit package: $POLKIT_PKG"

#+END_SRC

* Module 4 — Package lists (required, critical, optional)
  :PROPERTIES:
  :CUSTOM_ID: m4-package-lists

  - =CRITICAL= — subset verified *by dpkg-query* after install; missing

* Module 5 — Install packages and verify
  :PROPERTIES:
  :CUSTOM_ID: m5-install
  :END:

  Attempts the whole =PKGS= list. On non-zero exit (often unrelated —
  e.g. a failing =virtualbox-dkms=), run recovery, then verify each
  =CRITICAL= package by =dpkg-query= — abort only if one of *those* is
  missing.

  Then installs =OPTIONAL= one-by-one with warnings.

  **New since v1:** the final =systemctl enable --now bluetooth=
  guarantees =bluetoothd= is running when the user opens
  =blueman-manager=. Bluez's postinst usually enables it, but not
  always on freshly-installed systems.

#+NAME: m5-install
#+BEGIN_SRC bash
log "Installing required packages…"
if ! sudo DEBIAN_FRONTEND=noninteractive apt-get install -y \
     -o Dpkg::Options::=--force-confdef \
     -o Dpkg::Options::=--force-confold \
     "${PKGS[@]}" 2>&1 | tee -a "$LOG"; then
  warn "apt-get install returned non-zero (may be unrelated to our packages)."
  warn "Attempting recovery…"
  sudo dpkg --configure -a >>"$LOG" 2>&1 || true
  sudo DEBIAN_FRONTEND=noninteractive apt-get install -f -y >>"$LOG" 2>&1 || true
fi

log "Verifying critical packages…"
MISSING=()
for p in "${CRITICAL[@]}"; do
  if ! dpkg-query -W -f='${Status}' "$p" 2>/dev/null \
       | grep -q '^install ok installed$'; then
    MISSING+=("$p")
  fi
done
if [ "${#MISSING[@]}" -gt 0 ]; then
  warn "Missing critical packages: ${MISSING[*]}"
  warn "Full log: $LOG"
  fail "Cannot proceed without: ${MISSING[*]}"
fi
log "All critical packages verified."

log "Installing optional packages (warnings only)…"
for p in "${OPTIONAL[@]}"; do
  if apt-cache show "$p" >/dev/null 2>&1; then
    sudo DEBIAN_FRONTEND=noninteractive apt-get install -y "$p" >>"$LOG" 2>&1 \
      || warn "Could not install optional: $p"
  else
    warn "Not in this release: $p (skipped)"
  fi
done

# Bluetooth daemon must be live for blueman-manager to see adapters.
sudo systemctl enable --now bluetooth >/dev/null 2>&1 \
  || warn "Could not enable bluetooth service; blueman may show no adapters until reboot."

#+END_SRC

* Module 6 — Third-party binaries (bluetuith, yazi)
  :PROPERTIES:
  :CUSTOM_ID: m6-binaries
  :END:

  Two tools not in apt. Both best-effort; never abort.
  - =bluetuith= — BT TUI, falls back to =bluetoothctl= if fetch fails
  - =yazi= — nicer file manager, falls back to =nnn= (already installed
    as a *critical* package in Module 5, so "no file manager" is
    impossible)

#+NAME: m6-binaries
#+BEGIN_SRC bash
mkdir -p "$LOCALBIN"

if ! command -v bluetuith >/dev/null 2>&1; then
  case "$(dpkg --print-architecture)" in
    amd64) BIN=bluetuith-linux-amd64 ;;
    arm64) BIN=bluetuith-linux-arm64 ;;
    *)     BIN="" ;;
  esac
  if [ -n "$BIN" ]; then
    log "Fetching bluetuith…"
    if curl -fsSL "https://github.com/bluetuith-org/bluetuith/releases/latest/download/$BIN" \
         -o "$LOCALBIN/bluetuith"; then
      chmod +x "$LOCALBIN/bluetuith"
    else
      warn "bluetuith fetch failed; Bluetooth falls back to bluetoothctl."
    fi
  fi
fi

if ! command -v yazi >/dev/null 2>&1; then
  case "$(dpkg --print-architecture)" in
    amd64) YZ=yazi-x86_64-unknown-linux-gnu.zip ;;
    arm64) YZ=yazi-aarch64-unknown-linux-gnu.zip ;;
    *)     YZ="" ;;
  esac
  if [ -n "$YZ" ]; then
    log "Fetching yazi (optional upgrade over nnn)…"
    tmp=$(mktemp -d)
    if curl -fsSL "https://github.com/sxyazi/yazi/releases/latest/download/$YZ" \
         -o "$tmp/yazi.zip" 2>/dev/null; then
      unzip -qo "$tmp/yazi.zip" -d "$tmp" 2>/dev/null
      find "$tmp" -type f -name yazi -exec install -m755 {} "$LOCALBIN/yazi" \; 2>/dev/null
      find "$tmp" -type f -name ya   -exec install -m755 {} "$LOCALBIN/ya"   \; 2>/dev/null
    fi
    rm -rf "$tmp"
    command -v yazi >/dev/null 2>&1 || warn "yazi fetch failed; using nnn."
  fi
fi

#+END_SRC

* Module 7 — Ensure ~/.local/bin on PATH
  :PROPERTIES:
  :CUSTOM_ID: m7-path
  :END:

  Idempotently appends to =~/.profile= and =~/.bashrc=; grep-gated so
  re-running doesn't duplicate the export.

#+NAME: m7-path
#+BEGIN_SRC bash
for RC in "$HOME/.profile" "$HOME/.bashrc"; do
  [ -f "$RC" ] || continue
  grep -q 'HOME/.local/bin' "$RC" \
    || printf '\nexport PATH="$HOME/.local/bin:$PATH"\n' >> "$RC"
done

#+END_SRC

* Module 8 — Sway config
  :PROPERTIES:
  :CUSTOM_ID: m8-sway-config
  :END:

  Creates =~/dotfiles/sway/config=.

  **Philosophy: do not touch sway.** Every focus / move / resize / split
  / workspace / session bind is copied verbatim from Debian's stock
  =/etc/sway/config=. TARDIS additions live on **unused keys only**.

  **Workspaces 1–9.** Stock sway binds 1–5; extended to 9 for both
  =workspace= (switch) and =move container to workspace= (send window).
  Keys 6–9 work on any keyboard.

  **Touchpad — physical buttons, not finger count.** =click_method
  buttonareas=: bottom-right = right click, bottom-left = left click.
  =middle_emulation enabled=: bottom-middle press = middle click.

  **nmtui fix.** Not fullscreen (sway pins undersized fullscreen
  surfaces top-left). Float at workspace size, launched through
  =nmtui.sh= which sleeps 0.2 s before ncurses queries terminal size.

  **Media keys restored.** Stock sway does not bind =XF86Audio*= or
  =XF86MonBrightness*=; re-added here.

  **Keyboard block is appended, not templated** (no placeholder risk).

  **Invariant:** this module writes the file only. =__POLKIT__= is
  resolved in Module 23.

#+NAME: m8-sway-config
#+BEGIN_SRC bash

* Module 9 — Sway helper: help.sh
  :PROPERTIES:
  :CUSTOM_ID: m9-help
  :END:

  Parses the *live* =~/.config/sway/config= so the shortcut list can
  never drift. **Searchable** (=wofi --dmenu= without =--insensitive=),
  so typing "focus" or "resize" filters live.

  Explicitly includes the resize-mode block (which lives inside
  =mode "resize" { … }= and would otherwise be skipped by a naive
  =^bindsym= grep), plus a one-line tip explaining that stock sway
  resize is a *mode*, not a modifier combo.

  The key column is rewritten so =$mod= / =Mod4= display as ="Super"= —
  because the actual config uses =$mod= and that's what a newcomer needs
  to see on the keyboard.

#+NAME: m9-help
#+BEGIN_SRC bash
cat > "$DOTFILES/sway/help.sh" <<'HELP_EOF'
#!/bin/sh
CONFIG="$HOME/.config/sway/config"

{
  printf '\n'
  printf '  TARDIS Sway — Keyboard Shortcuts\n'
  printf '  ═══════════════════════════════════════════════════════════\n'
  printf '\n'
  printf '  Resize is a MODE: press Super+R, use arrows, Enter/Esc exits.\n'
  printf '  Move/resize a floating window by mouse: Super + drag (or right-drag).\n'
  printf '  Type in the search box to filter this list.\n'
  printf '\n'
  printf '  %-44s %s\n' "Action" "Shortcut"
  printf '  %-44s %s\n' "────────────────────────────────────────────" "──────────────────"
  printf '\n'

  # All top-level bindsym lines, formatted and de-duplicated
  grep -E '^bindsym ' "$CONFIG" \
    | sed -E 's/^bindsym //' \
    | awk '{
        key = $1
        rest = $0
        sub(/^[^ ]+ /, "", rest)
        if (match(rest, /#[^#]*$/)) {
          desc = substr(rest, RSTART + 1)
          sub(/^[[:space:]]+/, "", desc)
        } else {
          desc = rest
        }
        gsub(/Mod4/, "Super", key)
        gsub(/\$mod/, "Super", key)
        printf "  %-44s %s\n", desc, key
      }' \
    | sort -u

  printf '\n'
  printf '  %-44s %s\n' "── Resize mode (press Super+R first) ──" "──────────"
  printf '  %-44s %s\n' "Shrink width"   "Left"
  printf '  %-44s %s\n' "Grow width"     "Right"
  printf '  %-44s %s\n' "Shrink height"  "Up"
  printf '  %-44s %s\n' "Grow height"    "Down"
  printf '  %-44s %s\n' "Exit resize mode" "Enter / Esc / Super+R"
  printf '\n'
} | wofi --dmenu --prompt "Shortcuts (type to filter)" --width 900 --height 600
HELP_EOF
#+END_SRC

* Module 22 — TARDIS-blue wallpaper
  :PROPERTIES:
  :CUSTOM_ID: m22-wallpaper
  :END:

  Pure Python gradient, no ImageMagick dependency. Guarded by existence
  check so re-running preserves any wallpaper the user replaced.

#+NAME: m22-wallpaper
#+BEGIN_SRC bash
if [ ! -f "$DOTFILES/wallpapers/current.ppm" ]; then
  log "Generating TARDIS-blue wallpaper…"
  python3 - "$DOTFILES/wallpapers/current.ppm" <<'PY_EOF'
import sys
w, h = 1920, 1080
top = (0x00, 0x14, 0x30)
bot = (0x00, 0x3B, 0x6F)
buf = bytearray(b'P6\n%d %d\n255\n' % (w, h))
for y in range(h):
    t = y / (h - 1)
    r = int(top[0] + (bot[0] - top[0]) * t)
    g = int(top[1] + (bot[1] - top[1]) * t)
    b = int(top[2] + (bot[2] - top[2]) * t)
    buf.extend(bytes((r, g, b)) * w)
open(sys.argv[1], 'wb').write(buf)
PY_EOF
fi

* Module 23 — Resolve polkit binary path
  :PROPERTIES:
  :CUSTOM_ID: m23-polkit-bin
  :END:

  Finds the actual authentication-agent binary on disk and substitutes
  =__POLKIT__= inside the sway config written by Module 8. If nothing
  is found, deletes the =exec __POLKIT__= line rather than leaving a
  broken exec.

  **Invariant:** must run AFTER Module 8.

#+NAME: m23-polkit-bin
#+BEGIN_SRC bash
POLKIT=""
for p in \
  /usr/bin/lxpolkit \
  /usr/libexec/lxpolkit \
  /usr/libexec/polkit-gnome-authentication-agent-1 \
  /usr/lib/polkit-gnome/polkit-gnome-authentication-agent-1 \
  /usr/lib/policykit-1-gnome/polkit-gnome-authentication-agent-1 \
  /usr/lib/mate-polkit/polkit-mate-authentication-agent-1 \
  /usr/lib/x86_64-linux-gnu/libexec/polkit-mate-authentication-agent-1 ; do
  if [ -x "$p" ]; then POLKIT="$p"; break; fi
done

if [ -z "$POLKIT" ]; then
  warn "No polkit authentication agent found on disk."
  sed -i '/__POLKIT__/d' "$DOTFILES/sway/config"
else
  log "Polkit agent: $POLKIT"
  sed -i "s|__POLKIT__|$POLKIT|" "$DOTFILES/sway/config"
fi

  :END:

  =backup_if_real= only backs up a *real* directory (never a symlink),
  so re-runs don't accumulate =~/.config/sway.bak-…= dirs.

#+NAME: m25-symlink
#+BEGIN_SRC bash
backup_if_real() {
  local t="$1"
  if [ -e "$t" ] && [ ! -L "$t" ]; then
    local b="$t.bak-$(date +%s)"
    warn "Backing up $t → $b"
    mv "$t" "$b"
  fi
}

log "Linking configs into $CONFIG…"
for d in sway waybar mako foot wofi wlogout gammastep kanshi; do
  backup_if_real "$CONFIG/$d"
  ln -sfn "$DOTFILES/$d" "$CONFIG/$d"
done
backup_if_real "$HOME/wallpapers"
ln -sfn "$DOTFILES/wallpapers" "$HOME/wallpapers"

#+END_SRC

* Module 26 — Hard verification gate
  :PROPERTIES:
  :CUSTOM_ID: m26-verify
  :END:

  Refuses to declare success unless:
  - polkit binary exists on disk
  - sway config contains the substituted =exec /…polkit= line
  - a file manager exists (=nnn= or =yazi=)
  - =files.sh= and =help.sh= are executable

  Failure = exit 1 with a message pointing at exactly what's wrong.
  This is the last line of defense against a broken desktop.

#+NAME: m26-verify
#+BEGIN_SRC bash
ERRS=""
[ -z "$POLKIT" ] || [ ! -x "$POLKIT" ] && ERRS="${ERRS}· no working polkit agent\n"
grep -qE '^exec /.*(polkit|lxpolkit)' "$DOTFILES/sway/config" 2>/dev/null \
  || ERRS="${ERRS}· sway config has no polkit exec line\n"
{ command -v nnn >/dev/null 2>&1 || command -v yazi >/dev/null 2>&1; } \
  || ERRS="${ERRS}· no file manager (nnn or yazi)\n"
[ -x "$DOTFILES/sway/files.sh" ] || ERRS="${ERRS}· files.sh not executable\n"
[ -x "$DOTFILES/sway/help.sh" ]  || ERRS="${ERRS}· help.sh not executable\n"

if [ -n "$ERRS" ]; then
  warn "Install verification FAILED:"
  printf "$ERRS" >&2
  warn "Do NOT log out into Sway until these are resolved."
  exit 1
fi

if [ ! -f /usr/share/wayland-sessions/sway.desktop ]; then
  warn "/usr/share/wayland-sessions/sway.desktop not found; your DM may not list Sway."
fi

if ! sudo dpkg --audit 2>/dev/null | grep -q .; then
  :
else
  warn "dpkg still has half-configured packages. The desktop will work,"
  warn "but 'sudo apt install …' will keep failing until you fix them, e.g.:"
  warn "  sudo apt remove --purge virtualbox-dkms   # if you don't need VBox"
  warn "  sudo apt install --reinstall virtualbox-dkms  # to rebuild it"
fi

log "Verified: polkit agent = $POLKIT"
if command -v yazi >/dev/null 2>&1; then
  log "Verified: file manager = yazi (nnn also present)"
else
  log "Verified: file manager = nnn"
fi

#+END_SRC
